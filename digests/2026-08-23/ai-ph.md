今日发布的 AI 产品中，**开发者工具数量最多（6 款）**，其次是 **AI 智能体与助手（5 款）**，显示编程 Agent 与 Agent 运行环境仍是当前最热赛道。值得注意的创新点是“反向集成”：Antigravity 将 Agent 嵌入现有 IDE，Epho 把编码 Agent 搬到云端，Plow Latch 为 Mac 上的 Agent 加装访问控制——核心思路都是让 Agent 更好地融入既有开发流。Supernova 与 Actx0 分别从“数据接入”和“记忆层”切入，补齐 Agent 生态的基础设施短板。**开源趋势明显**，fx、OneCLI、Flunkey 等均选择开源，而闭源产品更多以 SaaS 形式提供垂直落地能力。
